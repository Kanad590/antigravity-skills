# 🗺️ Mental Model 10: The 12-Cluster Cognitive Routing Atlas

---

## ⚡ Core Premise

An advanced AI assistant operating in complex multi-agent environments cannot rely on monolithic, brute-force context stuffing or brittle flat-keyword lookups. When an agent has 137+ tools and skills, flat matching causes context bloat, token exhaustion, and catastrophic semantic confusion (e.g. routing an accessibility "focus trap" to financial "scam traps").

The **12-Cluster Cognitive Routing Atlas** partitions the entire agent action space into 12 mutually exclusive, comprehensively exhaustive functional clusters governed by a dynamic **3-Gear Cognitive Transmission**.

---

## ⚙️ The 3-Gear Cognitive Engine

```
       ┌───────────────────────────────┐
       │   Incoming Natural Prompt     │
       └──────────────┬────────────────┘
                      ▼
       ┌───────────────────────────────┐
       │     Cognitive Gearbox         │
       ├───────────────────────────────┤
       │ 🏎️ Gear 1: Sprint Mode        │──► Zero Filter Overhead (Status, File IO, Git)
       │ 🎨 Gear 2: Craft Mode         │──► Lateral Engineering (Animation, Code, Studio)
       │ 🧘 Gear 3: Deep Mind Mode     │──► Mandatory Triad (ToM, Anti-Trap, UDBE)
       └──────────────┬────────────────┘
                      ▼
         12-Cluster Semantic Router
                      ▼
   Predicted Skills + MCP Server Toolchains
```

1. **🏎️ Gear 1: Sprint Mode (Operational & Automated)**
   - *Scope:* Git operations, system administration, quick checks, container logs, file transforms.
   - *Rule:* Zero filter overhead. Direct tool invocation without psychological evaluation or decorative verbosity.
2. **🎨 Gear 2: Craft Mode (Production & Generative)**
   - *Scope:* 2D/3D animation, code architecture, video production, graphic layouts, document design.
   - *Rule:* Lateral engineering, GPU prioritization (`DRI_PRIME`), full output verification.
3. **🧘 Gear 3: Deep Mind Mode (Strategic & Advisory)**
   - *Scope:* High-stakes life forks, commercial product reviews, offline vendor reliability, exam strategy.
   - *Rule:* Mandatory Triad active:
     - *Filter 1:* Theory of Mind & Anti-Sycophancy (Ashlesha-Rahu radar, zero unearned flattery).
     - *Filter 2:* Authentic Human Prose (elimination of 43 AI-isms, 21 pattern categories).
     - *Filter 3:* Divergent Lateral Thinking (PO, SCAMPER, Concept Fan).

## 🛡️ Negative Semantic Guards

To prevent tool selection collisions, strict negative boundary guards are enforced:
- **"Trap" Collision:** UI focus traps / keyboard navigation traps route to **C8 (Visual Design & UI)**, NOT **C1 (Financial/Commercial Traps)**.
- **"Puppet" Collision:** Puppet configuration management routes to **C6 (Infrastructure)**; 2D Cutout Puppet animations route to **C9 (Animation & Media)**.
- **"Audit" Collision:** Pre-push git/secret audits route to **C12 (Code Quality)**; Agent completion audits route to **C5 (Verification)**; Commercial shop audits route to **C3 (Offline Trust)**.
